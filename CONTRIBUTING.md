# Contributing to BOSC Community Library

First off, thank you for considering contributing to BOSC Community Library! 🎉

## How Can I Contribute?

### Reporting Bugs

- Check existing issues first
- Use the **Bug Report** template
- Include steps to reproduce
- Describe expected vs actual behavior

### Suggesting Features

- Use the **Feature Request** template
- Explain the problem this feature solves
- Describe your proposed solution

### Submitting Pull Requests

1. **Fork the repository**
2. **Create a feature branch**
   or
   
3. **Make your changes**
- Keep changes focused and small
- Write clear commit messages
- Test your changes locally

4. **Push and open a PR**
   - Use the **Pull Request template**
- Link related issue (e.g., "Fixes #12")

## Branch Naming Convention

| Type | Branch name |
|------|-------------|
| Bug fix | `fix/brief-description` |
| New feature | `feature/brief-description` |
| Documentation | `docs/brief-description` |
| Refactoring | `refactor/brief-description` |
